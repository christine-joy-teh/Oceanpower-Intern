绿色道路 海川EC系列沥青混凝土温拌添加剂 —沥青混凝土路面节能减排、低温施工的最佳选择

温拌沥青混合料（WMA）是一类拌合温度介于热拌沥青混合料（HMA）和冷拌沥青混合料（CMA）之间，性能达到或超过热拌沥青混合料的新的节能减排沥青混合料。

一 产品介绍

EC-130沥青混凝土温拌添加剂是一种含水无机矿物材料（俗称沸石），其中含有的水分可以在100℃左右持续释放出来，与沥青作用使之发泡，降低沥青粘度，从而使沥青混凝土的拌合及施工温度降低20~35℃。

EC-120沥青混凝土温拌改性剂是一种聚烯烃类的降粘改性剂，EC-120的加入可以改变沥青的粘温曲线，降低沥青高温粘度，从而使沥青可以在相对较低的温度条件下与集料拌合均匀。

产品优势：
- 明显降低沥青混凝土生产能耗
- 可减少CO2等气体以及粉尘的排放量
- 改善施工环境
- 较低的拌和温度有利于减少施工过程中沥青的老化
- 延长沥青混凝土拌和设备使用寿命，降低设备维修成本
- 温拌沥青混凝土铺筑的路面更容易实现再生

二 技术分析

1 经济适用 节约能源：温拌沥青混凝土相对于热拌沥青混凝土，拌和施工温度降低了30℃左右。因此采用温拌沥青混凝土技术节省燃油，每生产1t热拌沥青混凝土需消耗8L燃料油，每吨温拌沥青混凝土可节约燃油2L~3L。

2 减排效果显著：根据试验测试，在生产沥青混凝土的过程中，以温拌沥青混凝土技术较热拌沥青混凝土降低施工温度30℃、我国年生产2.8亿吨沥青混凝土计，若全部采用温拌沥青混凝土技术来生产，每年可减少约75.6万吨的CO2以及75%~90%的烟尘排放。

热拌与温拌过程的排放比较（测试项目 / 单位 / HMA / WMA / 降幅%）：
- CO2：%：2.6 / 1 / 61.5
- NOx：mg/m³：151 / 40 / 73.5
- CO：mg/m³：104 / 91.3 / 12.2
- SO2：10000mg/m³：13 / 3.3 / 74.6
- 烟尘：mg/m³：5.6 / 2.59 / 53.8

国家环境分析测试中心混凝土摊铺现场检测结果（测试项目 / 单位 / 热拌 / 温拌 / 降幅%）：
- 沥青烟：mg/m³：21.1 / 2.06 / 90.2
- 苯可溶物：mg/m³：19.5 / 0.58 / 97.0
- 苯并芘：mg/m³：0.094 / 0.019 / 79.8

3 性能良好：按《公路沥青及沥青混合料试验规程》（JTG E20-2011）的规定，采用浸水马歇尔试验和冻融劈裂强度试验来评价沥青混凝土的水稳性，采用车辙试验进行动稳定度的测定。结果表明，添加EC系列温拌剂的温拌沥青混凝土性能良好，各项性能指标与普通热拌沥青混凝土相当或优于普通沥青混凝土。测试覆盖不同温拌剂掺量不同级配（AC13-1、AC13-2、AC16-1、AC16-2）下的马歇尔稳定度、劈裂抗拉强度、动稳定度等指标，EC-120、EC-130均表现良好。

三 应用范围

温拌技术可应用于任何热拌技术应用的范围，特别适用于特殊场合与环境下的施工：
（1）超薄罩面——有效解决超薄罩面压实难的问题
（2）长大隧道工程——减少沥青烟排放量，有效改善隧道施工环境
（3）低温季节、寒冷地区路面施工——有效延长施工期
（4）沥青混凝土集中厂拌再生——显著提高旧料再生利用率
（5）人口密集区、城市道路——减少路面施工对周围群众生活的影响
